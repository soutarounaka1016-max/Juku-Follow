# Juku Follow

塾講師が「今日の授業」「宿題の状態」「次に対応すべき生徒」を一画面で把握するためのデモWebアプリです。

## 主な機能

- 今日の授業と要対応生徒のダッシュボード
- 生徒の追加・編集・検索・学年絞り込み
- 授業記録、理解度、授業中の様子、次回対応の保存
- 宿題の追加、期限、提出状態の管理
- 宿題未提出、期限超過、要復習、授業記録未入力の自動判定
- 生徒ごとの宿題・授業履歴
- ブラウザ内保存と初期データへのリセット
- PC、iPad、スマートフォン向けレスポンシブ表示

初期状態はすべて架空データです。入力内容はブラウザの `localStorage` に保存され、外部サーバーへ送信されません。

## 公開

`main` への反映後、GitHub ActionsからGitHub Pagesへ自動公開します。
